01 — The practice

What I actually do all day

  • Agree what "working" means. An SLI that reflects the user, an SLO with a target people accept, an error budget that makes the trade-off visible.
  • Instrument before optimising. Logs, metrics and traces that answer a question. If an alert cannot name an action, it is noise.
  • Fix the class, not the instance. Postmortems that end in a change to the system, not a note to be careful.
  • Delete toil. Automated review, self-service pipelines, agents doing the repetitive parts.
  • Make capacity boring. Load tests before launches, headroom measured rather than hoped for.
  • Own the pager. 24/7 on-call for regulated financial infrastructure, all SLAs met.

03 — Featured project

A protein analyser in the browser

A protein analyser that runs entirely in the browser. Live records from UniProt, Ensembl and RCSB PDB; all the computing compiled from Rust to WebAssembly; no backend on the critical path.

03 — Featured project, continued

How it is built

  • Network in TypeScript, compute in Rust. WebAssembly cannot fetch cleanly, so TypeScript performs the requests and the Rust core decides which URLs to call and how to read them — testable logic, still Rust.
  • Two renderers. WebGL when the browser offers it; the same mesh, lighting and depth cueing rasterised on the CPU when it does not.
  • Tests without a browser. Rust domain tests, headless Node checks over the ABI and 3D maths, plus a Playwright suite against the built app.
  • One wrangler deploy. A Cloudflare Worker serves the bundle and answers /api/*. CI deploys only after every job passes, then reads the live URL back to confirm the pages and the wasm binary.
  • Honest failures. Unreachable API, unparseable file, DNA input — each gets a card that names the problem.

04 — Applied research

TurboQuant: half the KV cache, no slower

Implementing TurboQuant (ICLR 2026) inside vLLM: 3-bit keys, 2-bit values, a full-precision ring buffer for recent tokens, and only the full-attention layers compressed.

30.9 %KV memory saved per GPU
914,144max tokens, up from 457,072
+3.1 %decode tok/s at 30k context
+5.7 %prefill tok/s at 30k context
8 × 3090and one 5090, measured

The interesting part was not the compression — it was updating memory accounting and the context-limit calculation so the scheduler stops over-committing the VRAM it thinks it still has.

07 — How I work

Four rules I keep coming back to

  • Measure first. “If you cannot measure it, you cannot improve it.” A number you cannot point at is an opinion.
  • Make failures honest. The worst incident is the one that looks like nothing happening. Systems should say what broke, in the interface, not in a dashboard nobody opens.
  • Automate the boring, not the judgement. Toil removal is easy to justify; incident response stays human, with machines doing the searching.
  • Leave the system better documented than you found it. Reliability is mostly what survives the next person's Tuesday.
