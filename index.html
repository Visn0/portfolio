Featured · Rust → WebAssembly

A protein analyser in Rust and WebAssembly

A protein analyser that runs entirely in the visitor's browser. Give it a sequence, a UniProt accession or an Ensembl protein ID — or import a FASTA, GenBank, GFF3 or PDB file — and you get composition, molecular weight, isoelectric point, a feature map, a hydropathy profile, and an interactive 3D structure. Records are fetched live from public databases; all the computing happens on your own CPU, compiled from Rust to WebAssembly.

LLM inference · applied research

TurboQuant — KV-cache compression for vLLM

vLLMCUDAPythonMoE

An implementation of TurboQuant (ICLR 2026, arXiv:2504.19874) wired into vLLM and benchmarked on real hardware. Three-bit keys and two-bit values cut KV-cache memory by 30.9 % per GPU and doubled the maximum context to 914,144 tokens, while decode throughput rose 3.1 % at 30k context instead of falling.
